What?
#+end_tb
#+attr_latex: :options [x=69,y=167.11,s=13.7,l=16.44,ind=16.06,bf=arial]
#+begin_tb
- Executing many independent small jobs simultaneously to use the hardware resource efficiently.
#+end_tb
#+attr_latex: :options [x=69,y=193.08,s=13.7,l=16.44,c=c070809,b]
#+begin_tb
When?
#+end_tb
#+attr_latex: :options [x=69,y=219.05,s=13.7,l=16.44,ind=22.52,bf=arial]
#+begin_tb
- It is not possible to combine multiple runs/tasks into a single application.
#+end_tb
#+attr_latex: :options [x=69,y=245.72,s=13.7,l=16.44,ind=22.52,bf=arial]
#+begin_tb
- Large parameter sweep based on the same application or workflow with dependent pipeline steps.
#+end_tb
#+attr_latex: :options [x=69,y=277.45,s=13.7,l=20.21,ind=22.52,bf=arial]
#+begin_tb
- Workflow involves runs that depend on independent software which does not scale

beyond a certain number of cores.
#+end_tb
#+attr_latex: :options [x=69,y=324.32,s=13.7,l=16.44,c=c070809,b]
#+begin_tb
Why?
#+end_tb
#+attr_latex: :options [x=69,y=350.29,s=13.7,l=20.19,ind=22.52,bf=arial]
#+begin_tb
- Nodes are getting denser with respect to resources such as number of cores/threads, GPU cards,

Memory.
#+end_tb
#+attr_latex: :options [x=69,y=396.45,s=13.7,l=20.18,ind=22.52,bf=arial]
#+begin_tb
- Applications do not necessarily scale even within a node: shared memory (OpenMP, MPI SHM,

pthreads).
#+end_tb

#+begin_tb
@@beamer:{\fontsize{18}{21.6}\selectfont \textcolor{c070809}{\textbf{@@Job manager inside SLURM@@beamer:}}}@@
- Submits jobs within a single large allocation across multiple nodes.
#+end_tb
#+attr_latex: :options [x=68.15,y=187.6,s=15.9,l=17.31,p=5.76,ind=22.52,bf=arial]
#+begin_tb
- Does not have to wait for small individual allocations like in SLURM arrays.
- Optimizes resources for each job based on requirements such that the queue is \\
  always full.
- Possibility of restarting failed/timed out jobs.
#+end_tb
#+attr_latex: :options [x=68.15,y=280.63,s=15.9,l=25.22,ind=22.52,bf=arial]
#+begin_tb
- One can also specify complex result-based job dependencies.

@@beamer:{\fontsize{18}{21.6}\selectfont \textcolor{c070809}{\textbf{@@Some caveats and drawbacks@@beamer:}}}@@
#+end_tb
#+attr_latex: :options [x=68.15,y=329.66,s=15.9,l=17.3,p=5.79,ind=22.52,bf=arial]
#+begin_tb
- One needs to estimate, the total time of all the jobs combined.
- Job/system state files get produced in the submission directory.
- Might bring some complexity into execution of a Singularity containers with embedded \\
  MPI-based codes.
- When problems arise, the log files may say little.
#+end_tb
