* A computer is
:PROPERTIES:
:BEAMER_opt: pg=6
:END:
#+beamer: \slidegraphics{figures/fundamentals-of-hpc/g06}
#+attr_latex: :options [x=68.12,y=140.02,s=18,l=19.44,ind=22.56,bc=cEE7628,bf=arial]
#+begin_tb
- a machine that processes data by \\
  executing instructions to perform \\
  calculations, automate tasks, and \\
  *solve complex problems* efficiently.
#+end_tb
#+attr_latex: :options [x=68.12,y=229.77,s=18,l=19.44,ind=22.56,bc=cEE7628,bf=arial]
#+begin_tb
- an *electronic system*. Its CPU \\
  (control unit and ALU) processes \\
  data, moves it over buses to memory \\
  (RAM, cache, storage), and talks \\
  to peripherals.
#+end_tb
#+attr_latex: :options [x=72.08,y=389.94,s=16,l=17.28,c=cFFFFFF]
#+begin_tb
A computer is *a programmable electronic system that processes data through hardware and software.* Hardware, \\
including the *CPU (control unit and ALU), memory, buses, and peripherals*, handles computation, data transfer, and \\
interaction. Software, such as the *operating system and applications*, directs hardware operations for automation, \\
problem-solving, and data processing.
#+end_tb
#+attr_latex: :options [x=670.68,y=352.03,s=18,l=21.6,b,i]
#+begin_tb
And Boolean logic, zeros and ones!
#+end_tb

Each node provides a range of resources, including CPU cores, memory, accelerators (e.g., GPUs), and local disk \\
storage. For simplicity, documentation typically refers to allocations in terms of the number of CPU cores. However, in \\
practice, *resource allocation is determined by the most restrictive resource requested*.
#+end_tb
#+attr_latex: :options [x=63.89,y=396,s=16,l=17.28,ind=22.56,bc=cEE7628,bf=arial]
#+begin_tb
- If a user requests all CPU cores on a node but no GPUs, the node is still considered *fully allocated*. Even though the \\
  GPUs remain idle, other users cannot access them because all CPUs are occupied.
#+end_tb
#+attr_latex: :options [x=63.89,y=442.56,s=16,l=17.28,ind=22.56,bc=cEE7628,bf=arial]
#+begin_tb
- Conversely, if a user requests only one CPU core, the system *rounds up the allocation to the smallest permitted* \\
  *unit*. The job then gets every CPU core in that unit.
#+end_tb
