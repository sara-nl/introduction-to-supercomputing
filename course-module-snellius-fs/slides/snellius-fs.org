* Overview of HPC applications
:PROPERTIES:
:BEAMER_opt: tw=820
:END:
#+beamer: \slidegraphics{figures/snellius-fs/gtext}
#+beamer: \only<2->{\fspanel{c177ABF}{0.22}{70,186}{890,292}}
#+beamer: \only<3->{\fspanel{cEE7628}{0.22}{70,300}{890,372}}
#+beamer: \only<4->{\fspanel{c2CA055}{0.22}{70,380}{890,452}}
#+attr_latex: :options [x=84,y=136,s=15.9,l=19.08,w=790]
#+begin_tb
*HPC applications* exploit the power of supercomputers or high-performance clusters with the goal of solving complex problems.
They perform intensive \alert{computations}, coordinate \alert{communications} between parallel processes, and manage \alert{input/output} operations on a high-performance file system.
#+end_tb
#+beamer: \only<2->{
#+attr_latex: :options [x=88,y=210,s=15.9,l=19.08,b,w=780]
#+begin_tb
Computations
#+end_tb
#+attr_latex: :options [x=88,y=234,s=13.7,l=16.44,w=780,ind=18,bf=cal]
#+begin_tb
Extensive numerical operations on a specific region of interest (/e.g./, mesh elements, particles, or even words in a text document).

- Ideal speedup is $P$ for $P$ processors at fixed total work; dependencies and imbalance reduce it.
#+end_tb
#+beamer: }
#+beamer: \only<3->{
#+attr_latex: :options [x=88,y=322,s=15.9,l=19.08,b,w=780]
#+begin_tb
Communications
#+end_tb
#+attr_latex: :options [x=88,y=346,s=13.7,l=16.44,w=780,ind=18,bf=cal]
#+begin_tb
Coordination and data exchanges between parallel processes to produce the final results.

- Cost depends on topology, message sizes and synchronization; more workers can add overhead.
#+end_tb
#+beamer: }
#+beamer: \only<4->{
#+attr_latex: :options [x=88,y=400,s=15.9,l=19.08,b,w=780]
#+begin_tb
I/O operations
#+end_tb
#+attr_latex: :options [x=88,y=424,s=13.7,l=16.44,w=780,ind=18,bf=cal]
#+begin_tb
Interactions with the file system to read input data, write output results, and perform intermediate data storage.

- Throughput depends on the file system and access pattern; more processes can increase contention.
#+end_tb
#+beamer: }

Input operations

#+begin_tb
- *Initialization data*: grids, genomic sequences, climate data, or text.
  - Massive files that require a high level of precision.
  - Involve parallel input operations.
#+end_tb
#+beamer: \only<2->{
#+attr_latex: :options [x=88,y=230,s=13.7,l=16.44,w=780,ind=18,bf=cal]
#+begin_tb
- *Job parameters*: small configuration files that coordinate the processes.
#+end_tb
#+beamer: }
#+beamer: \only<3->{
#+attr_latex: :options [x=88,y=296,s=15.9,l=19.08,b,w=780]
#+begin_tb
Output operations
#+end_tb
#+beamer: }
#+beamer: \only<3->{
#+attr_latex: :options [x=88,y=320,s=13.7,l=16.44,w=780,ind=18,ind2=16,bf=cal]
#+begin_tb
- *Restart files* or checkpoints enable job continuation in the event of an interruption.
  - Large files that require full precision of simulation data.
  - Involve periodic parallel output operations.
#+end_tb
#+beamer: }
#+beamer: \only<4->{
#+attr_latex: :options [x=88,y=386,s=13.7,l=16.44,w=780,ind=18,ind2=16,bf=cal]
#+begin_tb
- *Analysis data* for visualization, post-processing and in-depth examination.
  - May be possible to use reduced precision or store a subset of the full-resolution data.
  - Involve periodic parallel output operations.
#+end_tb
#+beamer: }
#+beamer: \only<5->{
#+attr_latex: :options [x=88,y=446,s=13.7,l=16.44,w=780,ind=18,bf=cal]
#+begin_tb
- *Job monitoring*: progress and performance logs, typically plain text from process 0.
#+end_tb
#+beamer: }

#+begin_tb
1. *Exploring file systems*:
   - Know the file systems of the table (home, scratch, project, archive)
   - Move between your home and scratch-shared and check the current location
2. *File management*:
   - Create, view, and edit files using basic terminal commands
   - Move, rename, and copy files between different file systems
3. *Directory management*:
   - Create and delete directories
   - Change into directories and manage file hierarchy
4. *File permissions*:
   - Check and modify file access permissions
5. *Disk usage monitoring*:
   - Monitor storage usage and available space across file systems

Objective
#+end_tb
#+attr_latex: :options [x=76,y=162,s=15.9,l=19.08,w=370]
#+begin_tb
Learn how to create, view, move, and rename files across different file systems in an HPC environment.
#+end_tb
#+attr_latex: :options [x=76,y=240,s=18,l=21.6,b]
#+begin_tb
Tasks
#+end_tb
#+attr_latex: :options [x=76,y=266,s=15.9,l=19.08,w=370,ind=18,bf=cal,p=2]
#+begin_tb
- Create a file in the ~home~ directory using ~touch~.
- Edit the file with ~nano~ or ~vim~, and view its contents with ~cat~.
- Copy the file to the ~scratch~ directory using ~cp~.
- Rename or move the file using ~mv~.
#+end_tb
#+attr_latex: :options [x=508,y=148,s=15.9,l=19.08,b,c=cC3E88D]
#+begin_tb
Key commands
#+end_tb
#+attr_latex: :options [x=508,y=174,s=13.7,l=17.5,w=400,c=cEEFFFF,code,ind=16,bc=cEEFFFF,bf=cal,p=1]
#+begin_tb
- ~touch <fname>~ - Create a new empty file
- ~nano <fname>~ or ~vim <fname>~ - Edit a file
- ~cat <fname>~ - Display the contents of a file
- ~cp <src> <tgt>~ - Copy files between directories
- ~mv <src> <tgt>~ - Move or rename files
#+end_tb
#+attr_latex: :options [x=508,y=310,s=15.9,l=19.08,b,c=cC3E88D]
#+begin_tb
Expected output

#+begin_tb
- ~cat~ prints the line you typed; ~ls /scratch-shared/$USER~ lists the copy; after ~mv~, ~ls~ shows the new name and not the old one.
#+end_tb

#+end_tb
#+attr_latex: :options [x=76,y=214,s=18,l=21.6,b]
#+begin_tb
Explanation
#+end_tb
#+attr_latex: :options [x=76,y=238,s=15.9,l=18.5,w=370,ind=18,bf=cal,p=1]
#+begin_tb
- Permissions are shown as ~rwxrwxrwx~ (for owner, group, others).
- ~r~ - read (4), ~w~ - write (2), ~x~ - execute (1).
- Numeric format: ~chmod 755~ means owner can ~rwx~, group and others can ~r-x~.
#+end_tb
#+attr_latex: :options [x=76,y=340,s=18,l=21.6,b]
#+begin_tb
Tasks
#+end_tb
#+attr_latex: :options [x=76,y=364,s=15.9,l=18.5,w=370,ind=18,bf=cal,p=1]
#+begin_tb
- Use ~ls -l~ to check the permissions of a file.
- Modify the file's permissions to allow read access for everyone using ~chmod 644~.
- Verify the permission changes with ~ls -l~.
#+end_tb
#+attr_latex: :options [x=508,y=160,s=15.9,l=19.08,b,c=cC3E88D]
#+begin_tb
Key commands
#+end_tb
#+attr_latex: :options [x=508,y=186,s=13.7,l=18,w=400,c=cEEFFFF,code,ind=16,bc=cEEFFFF,bf=cal,p=2]
#+begin_tb
- ~ls -l~ - view file permissions
